# Drone System Design
#### Client Name: Cooper Taylor

## Project Requirements
The system requires a PCB made of below components embedded in a single solution:
- 2 drone ESCs with capability of a minimum of 50 amps. The ESCs would use oneshot125 protocol and would be for drone motors.
- A UBEC that is capable of delivering up to 20Amps and feeding 8.4V and 5V outputs.
- The main power input to the system will be around 10V to 10.5V
